# projeto-aline-career-dreamer
O Career Dreamer é uma página web que ajuda estudantes a descobrir carreiras em tecnologia a partir de seus hobbies e interesses. Os dados vão para uma API com IA, que devolve as carreiras mais compatíveis e um roteiro de estudos. No projeto, corrigi bugs de validação, responsividade e acessibilidade, usando HTML5, CSS3 e JavaScript puro.
